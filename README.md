# Atlas TaskFlow

## What is it?

Atlas TaskFlow is a course project that will show the workflow for creating a cloud based application fully.

This project will include working with
- SSMS
- Visual Studio
- Azure
- Github
- ASP.Net Core
- Relational Databases
- Object Oriented Programming

## Core Idea

So. My main idea for Atlas TaskFlow is to create a system that works for instructors and students coherently. 
I want instructors to be able to use Atlas to create classrooms where they can assign work or tasks to students belonging
to those specific classrooms.

Students, will have a simpler time managing those tasks and also have the ability to create and manage tasks of their own.

## Main Issue

My main gripe with our current system being used, D2L, is that there's only a list of the instructor assigned tasks, but there's
no actual functionality there for students to truly interract with and make use of something meaningful.

Students still need a planner or some other medium to truly manage their workload still.
